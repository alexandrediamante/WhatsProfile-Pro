🔌 Guia de Integração REST para Sistemas Externos

Qualquer outro software, CRM, bot ou backend pode consultar dados do WhatsApp e alterar recados fazendo simples requisições HTTP GET e POST.

GET /api/contact/:phone

Retorna todas as informações do contato, foto de perfil e screenshot da barra lateral em JSON.

Parâmetros de Query opcionais:
  • screenshot=false - Desativa a captura de tela para resposta ultra-rápida.
Exemplo cURL:
curl -X GET "http://localhost:3000/api/contact/5511999999999"
Exemplo Node.js (fetch):
const response = await fetch('http://localhost:3000/api/contact/5511999999999');
const data = await response.json();
console.log(data.data.contactInfo.name, data.data.profilePicture.url, data.data.screenshot.imageUrl);
GET /api/contact/:phone/picture

Obtém a URL direta da foto de perfil em alta resolução.

curl -X GET "http://localhost:3000/api/contact/5511999999999/picture"
POST GET /api/user/status

Atualiza o recado/status do WhatsApp conectado. Aceita tanto POST com body JSON quanto GET com query param ?message=....

Exemplo GET (via navegador ou URL):
curl -X GET "http://localhost:3000/api/user/status?message=Atendimento%20Online"
Exemplo POST JSON:
curl -X POST "http://localhost:3000/api/user/status" \
  -H "Content-Type: application/json" \
  -d '{"statusMessage": "Em reunião no momento"}'
GET /api/status

Consulta se o WhatsApp Web está online, pronto ou aguardando QR Code.

curl -X GET "http://localhost:3000/api/status"
